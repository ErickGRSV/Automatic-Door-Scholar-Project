# Automatic-Door-Scholar-Project
Projeto acadêmico desenvolvido para controle de acesso à área da gestão escolar utilizando biometria e ESP.

## Objetivo

Desenvolver um sistema capaz de autenticar funcionários autorizados por biometria e liberar o acesso à área da gestão.

## Funcionalidades

- Cadastro de funcionários autorizados
- Cadastro de biometria
- Autenticação por biometria
- Abertura automática da porta
- Abertura manual em situações excepcionais
- Sinalização por LED e buzzer
- Registro de tentativas de acesso
- Bloqueio após 5 tentativas inválidas
- Funcionamento na rede local

## Estrutura do projeto

- `esp/` — Código do ESP e controle dos componentes.
- `banco/` — Banco de dados e scripts.
- `servidor/` — Comunicação entre o ESP e o banco de dados.
- `docs/` — Documentação do projeto.
